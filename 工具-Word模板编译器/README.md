# Word 模板编译器

在 Word 文档里写 `{{字段}}`，用一份 JSON 数据一次性替换全部内容，版式和格式保持不变。
适合合同、通知、报价单、证明、验收单这类「大部分固定、少数字段变化」的文档。

## 运行环境

- Python 3.10 或以上（Windows / macOS / Linux 都可以）
- python-docx：`pip install python-docx`
- 可选：LibreOffice（用于一键导出 PDF；没有的话可以用 Word 自己另存为 PDF）

## 快速开始

双击 `一键启动.bat` 打开图形界面（把 Word 文件直接拖到这个 bat 上也可以，会自动载入该文件）：

macOS / Linux 用户：双击 `启动工具.command`，或在终端执行 `python3 start_tool.py`
（.bat 是 Windows 专用；Mac 上如果界面打不开，先 `brew install python-tk`）。

1. 在「Word 模板」一行点「浏览…」选中要做的那份 .docx
2. 点「生成数据模板」得到 JSON 骨架，填好里面的数据
3. 在「数据文件」一行选中该 JSON，点「开始生成文档」

也可以指定任意路径下的文件，工具不要求模板放在本目录。命令行方式：

```
python -m wordfill 扫描 模板.docx                        # 列出所有特殊字段
python -m wordfill 生成数据 模板.docx -o 数据.json        # 生成 JSON 骨架
python -m wordfill 填充 模板.docx 数据.json -o 结果.docx   # 生成文档
python -m wordfill 检查 模板.docx 数据.json               # 检查数据是否齐全
python -m wordfill 转PDF 结果.docx                       # 导出 PDF
```

## 字段语法

| 写法 | 说明 |
| --- | --- |
| `{{姓名}}` | 普通字段 |
| `{{客户.电话}}` | 多级字段，对应 JSON 里的嵌套对象 |
| `{{金额\|千分位}}` | 1,234,567.89；`{{金额\|#,##0.00}}` 可指定两位小数 |
| `{{金额\|人民币大写}}` | 壹佰贰拾叁万肆仟伍佰陆拾柒元捌角玖分 |
| `{{日期\|yyyy年M月d日}}` | 日期格式化，模式支持 y yy M MM d dd H HH m mm s ss |
| `{{备注\|默认:无}}` | 数据缺失时使用的默认值 |
| `{{$today}}` / `{{$now}}` | 内置：当天日期、当前时间 |
| `{{@公章}}` / `{{@公章\|宽=4cm}}` | 插入图片，JSON 里填图片路径 |
| `{{表格:明细}}` / `{{表格:明细\|无表头}}` | 在这个位置插入一整张表格，表头、列宽、列格式、行数都由 JSON 决定 |
| `{{#if 条件}}…{{else}}…{{/if}}` | 条件内容，可整段、行内或整行 |
| `{{#unless 条件}}…{{/unless}}` | 条件取反 |
| `{{#each 明细}}…{{/each}}` | 重复内容，可整段（含表格）或重复表格行 |
| `{{_index}}` | 循环序号，从 1 开始 |

条件表达式支持 `!`、`==`、`!=`、`>`、`<`、`>=`、`<=`、`&&`、`||`。

JSON 字符串里用 `\n` 表示换行：替换到 Word 时是真正的换行（`w:br`），行首空格保留，
适合 SQL 语句、代码片段和多行说明；把模板里那个标记的字体设成 Consolas 就是等宽效果。

### 行数不固定的表格

两种做法，可混用：

1. 模板里已经画好表头和一行格式：用 `{{#each 明细}} … {{/each}}` 包住那一行，行数随数据自动增减，样式沿用模板。
2. 模板里不放表格：单独写一行 `{{表格:明细}}`，整张表由 JSON 生成（表头文字、列数、列宽、列格式、行数都能变）：

```json
"明细": {
    "表头":   { "序号": "1.3cm", "品名": "5cm", "数量": "2cm", "小计": "2.6cm" },
    "列格式": { "小计": "千分位" },
    "合并列": ["序号"],
    "字号": 9.5,
    "行": [ { "序号": 1, "品名": "工业服务器", "数量": 2, "小计": 73600 } ]
}
```

也可以简写成 `"明细": [ {"品名": "…", "数量": 2} ]`，表头自动取数据的键名。
`合并列` 会把同一列里连续相同的内容纵向合并成一个单元格（数据库字段清单里把相同表名合并很常用）；
`字号` 不给时按列数自动取 10.5 / 9.5 / 8.5 磅。
生成的表格自动带浅灰边框、表头灰底加粗、数字列右对齐，跨页时重复表头。

## 实现要点

- **跨 run 替换**：Word 会把一段文字切成多个 run，`{{甲方名称}}` 常常被拆开。
  引擎按字符建立「字符 → 文本节点」映射，只替换标记覆盖的字符，标记之外的加粗、
  字号、颜色、下划线全部保留。
- **循环与条件**：整段循环/条件在块级处理（复制段落、表格），表格行循环在行级处理
  （复制 `<w:tr>`）。`{{#each}}` 允许与字段写在同一单元格里，单元格内的行内条件
  不会被误判成整行条件。
- **图片**：按图片原始比例缩放，可以指定宽度，超过正文宽度时自动限制。
- **内容控件**：文档里的 Word 表单域（内容控件）如果标题/标记与 JSON 键名相同，
  也会被一起填充。
- **缺失数据**：默认把没数据的字段原样保留（方便检查），可用 `--blank` 改为留空，
  或用 `--strict` 直接报错。

## 已知限制

- 不支持 `.doc` 旧格式，请先在 Word 里另存为 `.docx`。
- 图片支持 PNG / JPG / GIF / BMP / TIFF，不支持 EMF、WMF 矢量图。
- 正文、表格、文本框、页眉、页脚里的字段都会处理；脚注、尾注、批注中的文字不处理。
- 开启修订模式（修订痕迹）时，插入/删除的文字按普通文字处理。
- 一键导出 PDF 依赖 LibreOffice；没有装的话可以用 Word 另存为 PDF。
