# 一份模板生成两种智能办公空间方案

这个示例将多种模板能力放进一份完整的交付方案：修改 JSON 后，项目介绍、设备行数、服务章节、验收表格的列数和行数会一起变化，固定的标题和版式沿用 Word 模板。

所有项目名称、设备价格、数量、日期和配置均为虚构演示数据。系统示意图为项目自绘图片，不含真实企业标识或客户资料。

## 三分钟体验

安装 Python 3.10+ 和 `python-docx` 后，在项目根目录运行：

```bash
python "工具-Word模板编译器/示例/智能办公空间/生成演示.py"
```

会在 `output/智能办公空间/` 生成 `轻量版交付方案.docx` 与 `旗舰版交付方案.docx`。输出目录已被 Git 忽略。

也可以打开 Word 填充图形界面，选中这里的 `交付方案模板.docx`，依次加载两份 JSON，各生成一份文档。

## 对比两份结果

| 变化 | 轻量版 | 旗舰版 |
| --- | --- | --- |
| 项目 | 青禾创作工作室，12 个工位 | 云栖协作空间，48 个工位 |
| 设备清单 | 3 行 | 6 行 |
| 设备预算 | 4,040.00 元 | 7,400.00 元 |
| 含服务总预算 | 5,640.00 元 | 11,600.00 元 |
| 服务章节 | 远程支持 | 2 个工作日驻场支持 |
| 验收方式 | 远程演示与资料核验 | 现场逐项核验 |
| 动态验收表格 | 3 列、3 条记录 | 4 列、6 条记录，增加验证方式 |
| 补充说明 | 未提供字段，使用默认文案 | 使用数据里的自定义说明 |

设备小计和预算合计由 JSON 提供，填充引擎负责格式化，不进行报价计算。演示脚本会检查金额是否一致；修改数量或单价时，也需要修改对应小计及预算。

## 这些变化如何实现

| 软件能力 | 模板写法或数据设置 | 在结果中的位置 |
| --- | --- | --- |
| 嵌套字段 | `{{项目.名称}}`、`{{项目.工位数}}` | 项目概况与页眉 |
| 跨文字片段替换 | `{{项目.摘要}}` 在模板中拆为两个 run | 首段加粗摘要仍完整替换 |
| 图片插入与缩放 | `{{@系统图\|宽=16cm}}` | 系统示意图 |
| 金额与日期格式 | `#,##0.00`、`人民币大写`、`yyyy年M月d日` | 预算与交付日期 |
| 整段条件 | `#if 启用驻场` 与 `#unless 启用驻场` | 自动选择服务章节 |
| 行内条件 | `#if 远程验收` 与 `else` | 同一段落中的验收方式 |
| 重复表格行 | `#each 设备` 与 `_index` | 设备清单自动增减、顺序编号 |
| 重复段落 | `#each 里程碑` | 按数据生成实施阶段 |
| 整表生成 | `{{表格:验收清单}}` | 表头、列宽、列数和行数由 JSON 指定 |
| 连续单元格合并 | `"合并列": ["模块"]` | 验收清单相同模块纵向合并 |
| 默认值 | `{{备注\|默认:本方案按约定范围交付，无补充事项。}}` | 轻量版的补充说明 |
| 多行文本 | JSON 字符串里的 `\n` 和缩进 | 运行配置中的 YAML 示例 |
| 页眉页脚替换 | 项目名称、编号、方案版本 | 每页标识与自动页码 |

模板包含控制标记，直接打开时会看到 `{{…}}`。对外展示软件效果时请查看生成后的两份文档。

## 自己修改一次

1. 复制一份数据到项目根目录的 `local/`，用于自己的项目。
2. 增减“设备”数组中的记录，并同步调整小计和预算，观察表格行数与序号变化。
3. 切换“启用驻场”和“远程验收”，观察服务章节和验收方式变化；启用驻场时需提供“驻场说明”。
4. 在“验收清单”的“表头”和各行中同步增加一列，观察整表结构变化。
5. 通过图形界面加载自己的 JSON，输出到 `output/`。图片路径按模板所在目录解析，自定义图片也可使用绝对路径。

希望 AI 以后按固定规则填写这份方案时，可从项目根目录打开“启动填写界面”，选择本模板生成骨架，再填写字段说明并打包成专用 Skill。普通 `#each` 循环可推断项目字段；`{{表格:验收清单}}` 本身不包含表头，生成骨架后需按这里的示例数据设置表格列名及说明。
