# 排查手册

先跑 `python scripts/wf.py check`（有模板就给模板，没有就用 `--keys-from 骨架.json` 或 `--config 字段配置.json`），多数问题它会直接指出。下面是按现象查。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 文档里还剩 `{{字段}}` | 数据里没有这个键，或键名与模板不一致（大小写、下划线、多级字段写成 `客户.名称`） | 对齐键名；确实没有内容就补 `""` 或用 `--blank` |
| 有字段没被替换但 check 说没问题 | 该标记在脚注、批注或公式对象里 | 工具只处理正文、表格、文本框、页眉页脚；把内容移到正文 |
| 表格没出现 | 值不是对象/数组，而是字符串或空串 | 表格字段必须给 `{ "表头": …, "行": [...] }` 或数组 |
| 表格少列/多列 | 行里的键与 `表头` 不一致 | `check` 会逐行报出缺哪列、多哪个键 |
| 表头顺序不对 | `表头` 是数组或对象，顺序就是列顺序 | 调整 `表头` 顺序 |
| 单元格内容被折成两行 | 列宽太窄 | 调大该列宽度，或整体加 `"字号": 9.5` 缩小字号 |
| 相同表名没有合并 | 没有配置 `合并列` | 加 `"合并列": ["表名"]`（只合并连续相同的值） |
| SQL/代码挤成一行 | JSON 里用了真实换行或 `\\n` | 用 `\n`；工具会转成 Word 里的真换行 |
| JSON 报语法错误 | 字符串里直接敲了回车、尾随逗号、用了中文引号 | 用 `"` 半角引号；多行用 `\n` |
| 日期显示成 2026-09-17 | 模板没写格式 | 标记改成 `{{日期\|yyyy年M月d日}}` |
| 金额没有千分位 | 模板没写格式 | 标记改成 `{{金额\|千分位}}` 或 `{{金额\|#,##0.00}}` |
| 人民币大写不对 | 值里带了货币符号或千分位 | 数据里给纯数字 `128600` |
| 图片没插进去 | 路径不对，或用了 EMF/WMF | 用 PNG/JPG；路径相对模板文件或用绝对路径 |
| PDF 导出失败 | 本机没有 LibreOffice | 用 Word 另存为 PDF，或在装了 LibreOffice 的机器上导出 |
| 提示缺少数据 | 数据里没有模板要求的键 | 补数据；或确认这次确实不填，用 `--blank` 留空并在交付说明里写明 |
| 模板改了以后字段对不上 | 模板和数据两头改名不一致 | 重新 `wf.py scan`，按新键名更新数据 |
| 生成的文档打不开/提示损坏 | 源模板本身异常，或生成时被占用 | 用 Word 另存一份模板再试；输出文件不要同时开着 |

## 交付前的三条硬检查

1. `wf.py check` 退出码为 0（或只剩可接受的提示）。
2. 生成结果里没有 `{{ }}` 残留。
3. 表格行数、合并单元格、多行 SQL 与预期一致（导出 PDF 抽查那一页）。
