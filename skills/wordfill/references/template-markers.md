# 给 Word 模板加标记

**只在用户明确要求给模板加/改标记，或要排查模板相关问题时读这份**；日常产出 JSON 的任务不需要分析模板。

工具靠 `{{...}}` 标记定位内容。标记可以写在任何位置：正文、表格、文本框、页眉页脚。

## 1. 语法速查

| 标记 | 用途 |
| --- | --- |
| `{{prd_name}}` | 普通字段，替换成数据里的值 |
| `{{客户.名称}}` | 多级字段，对应 JSON 里嵌套一层的对象 |
| `{{金额\|千分位}}`、`{{金额\|0.00}}`、`{{金额\|人民币大写}}` | 金额格式化 |
| `{{日期\|yyyy年M月d日}}` | 日期格式化（`yyyy`/`M`/`MM`/`d`/`dd`/`HH`/`mm`） |
| `{{备注\|默认:无}}` | 数据缺失时的默认值 |
| `{{@公章}}`、`{{@公章\|宽=4cm}}` | 插入图片 |
| `{{表格:改造清单}}`、`{{表格:改造清单\|无表头}}` | 整张表格由数据生成，行数/列数都能变 |
| `{{#each 员工}} … {{/each}}` | 重复内容：模板里已有的表格行或整段，按数据条数复制 |
| `{{#if 需要停机}} … {{else}} … {{/if}}` | 条件内容，可整段、行内、整行 |
| `{{_index}}` | 循环序号（从 1 开始） |
| `{{$today}}`、`{{$now}}` | 自动填当天日期 / 当前时间 |

标记本身可以设字体、字号、加粗，替换后会保留标记所在位置的格式（中文用宋体、英文用 Consolas 之类的设置照常生效）。

## 2. 在 Word 里手写

1. 在需要变化的地方输入 `{{字段名}}`，字段名用英文、数字、下划线或中文都行，只要和数据键一致。
2. 表格行数不固定时，按下面两种做法之一加标记。
3. 存盘后用 `wf.py scan 模板.docx` 确认字段都能扫描出来。

注意：

- 用**半角**大括号 `{{ }}`，不要用全角 `｛｛ ｝｝`。
- 标记要写在一起；即使 Word 把它拆成几段文字（改过字体、加粗时常见），程序也能识别。
- 条件与循环的成对标记要么各占一个段落，要么写在同一个段落里；不要一半在一段、一半在下一段。

## 3. 表格行数不固定：两种做法

| 做法 | 模板里怎么写 | 什么时候用 | 数据写法 |
| --- | --- | --- | --- |
| 行循环 | 把要重复的那一行用 `{{#each 明细}}` … `{{/each}}` 包住（可以放在同一行的第一个/最后一个单元格，也可以标记单独占一行包住多行） | 模板里已经有表头和行样式，想保留格式 | `"明细": [ {…}, {…} ]` |
| 整表生成 | 在表格该出现的位置单独写一行 `{{表格:改造清单}}` | 模板里没有表格，或列数、表头也要跟着数据变 | `"改造清单": { "表头": {…}, "合并列": [...], "行": [ {…} ] }` |

两种可以混用；同一份文档里放多个 `{{表格:…}}` 互不影响，各自插入到标记所在位置。

## 4. 用脚本批量加标记

模板很长、或者要把某个 Excel 里的字段名批量变成标记时，写一个一次性的 python-docx 脚本比手工敲快，例如把"（此处填写需求名称）"替换成 `{{prd_name}}`：

```python
from docx import Document
doc = Document("模板.docx")
for para in doc.paragraphs:
    for run in para.runs:
        if "（此处填写需求名称）" in run.text:
            run.text = run.text.replace("（此处填写需求名称）", "{{prd_name}}")
doc.save("模板_加标记.docx")
```

改完模板一定要重新 `wf.py scan`，并与既有数据 JSON 对照，确认键名没有变。

## 5. 检查清单

- [ ] `wf.py scan` 能列出全部预期字段，没有漏、没有多余
- [ ] 表格字段的标记与数据键同名（`{{表格:改造清单}}` ↔ `"改造清单"`）
- [ ] 条件/循环成对出现，没有单边标记
- [ ] 字段名和数据 JSON 完全一致（含大小写、下划线）
